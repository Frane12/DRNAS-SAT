# DRNAS PCMAX Weighted VeriPB2 original evidence

11 standard VeriPB 3.0.2 UNSAT proofs, each independently rechecked against an unchanged SHA-256-pinned original CNF in the new repository.

The full retrospective source set has 20 instances; the other 9 returned UNKNOWN and do not have UNSAT proofs.

Original run: https://github.com/Frane12/AndroidGameTest/actions/runs/43719601339

Reproduce each accepted example: veripb --cnf 05/original.cnf 05/weighted.pbp

This is a restricted SAT benchmark family and is not evidence of a general SAT complexity breakthrough.
