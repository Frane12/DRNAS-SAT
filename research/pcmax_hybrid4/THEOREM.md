# DRNAS MATH-HYBRID4 — configuration-compatibility hole

**Status: mathematically proven for a constructed synthetic CNF; locally validated RUP trace.** External VeriPB acceptance must be reported separately. No P=NP/P=coNP claim.

## 1. Explicit six-job configuration family

Two identical machines each accept either the empty pattern or exactly one of seven triples (job IDs **0–5**):

| Pattern | Allowed three-job set |
|---|---|
| E0 | {0,1,5} |
| E1 | {0,2,3} |
| E2 | {0,2,4} |
| E3 | {1,3,4} |
| E4 | {1,2,5} |
| E5 | {0,3,5} |
| E6 | {1,2,3} |

Each job must be assigned to **exactly one** machine. The source CNF contains the at-least-one and pairwise at-most-one clauses for each job, plus source-backed ordered BDD implications, asserted roots and terminal units for the two local languages. The SHA-256 recorded by the certificate belongs to the generated CNF. This is **not** a SAT competition PCMAX original.

## 2. UNSAT proof by pairwise compatibility

All pairs of the seven triples intersect. Both machines must take three jobs to cover all six. Two disjoint triples would be necessary, but none exist. Therefore **UNSAT**.

This check is polynomial in an explicitly given two-machine configuration list, but it does **not** extend to a polynomial algorithm for general exact cover on an arbitrary number of machines: selecting a disjoint exact cover from many triples is NP-complete (X3C).

## 3. Fractional witness and signed integer lattice witness

Each of the four patterns E2, E3, E4, E5 occurs with weight 1/4 on **each** machine. Each job belongs to exactly two of those four patterns, so its fractional total is 2 × (2/4) = 1. This proves the ordinary assignment LP relaxation is feasible.

With 1_E the 6-component incidence vector of pattern E, there is also an **integer** identity:

    -1_E1 + 1_E2 + 1_E5 + 1_E6 = (1,1,1,1,1,1).

The signed coefficients add up to -1+1+1+1=2, matching the number of machines. Thus the demand vector augmented by the machine-count row belongs to the integer lattice generated by the allowed nonempty local configurations. No necessary congruence invariant **that holds for all integer linear combinations** can separate the target. The negative coefficient makes this identity **not** an actual schedule.

This does NOT mean all modular algorithms fail: modulo arithmetic plus the constraint that exactly two valid configurations must be chosen is stronger than integer lattice membership.

## 4. Measured separation of small GF(2) signatures

Let a support be any nonzero 6-bit mask A. The signature of local pattern p is parity(popcount(p & A)). With two independently accepted local patterns, their signatures XOR.

The standalone checker exhaustively evaluates **63** individual supports and all **1,953** unordered pairs of distinct supports. None excludes the all-ones target. It also checks all **63 subset-count projections**: for every job subset A, a pair of locally allowed patterns matches the target cardinality |A| on that subset **exactly** (even though the pair need not be a globally valid assignment).

A **three-dimensional** signature succeeds: supports (in decimal masks) A=4, B=11, C=33. The local signature set is {0,1,5,7}; its 2-fold XOR sum omits the required target signature 3. Thus 3D GF(2) configuration compatibility detects UNSAT, whereas every 1D or 2D projection fails. This is a minimal-dimension result **within this specific family of parity projection tests**, not a lower bound for general SAT proofs.

## 5. Machine-readable and externally checkable proof

- `emit.py` constructs `source.cnf`, `certificate.json`, `proof.drup`, and `proof.pbp` from scratch. The full proof is **31 RUP steps**, derived from source-BDD prefix exclusions and exact-one clauses.
- `check.py` separately parses the original generated CNF and verifies each exact-one clause, BDD source transition, terminal/root unit, selector partition, all 64 local assignments, no exact cover, exact fractional and signed witness, every 1D and 2D parity projection, and **each RUP step against the unchanged CNF**.
- `test.py` checks a SAT control (one complementary triple added to each machine's language), verifies an explicit satisfying model against every source clause, and rejects seven deliberately corrupted inputs/certificates.
- `veripb --cnf source.cnf proof.pbp` is the independent VeriPB 3.x acceptance test. A GitHub Actions workflow is provided; until its log says `s VERIFIED UNSATISFIABLE`, the external proof status is **unconfirmed**.

RUP proof length **31** is for this tiny synthetic formula. Search and proof-size asymptotics remain open; this cannot establish a general polynomial-time complete SAT procedure. Existing mathematical ideas of hypergraph exact cover, integer-lattice holes and linear/cutting-plane relaxations are not claimed as first discoveries here.

## 6. Reproduce locally

```sh
python3 research/pcmax_hybrid4/emit.py --out /tmp/hybrid4_unsat
python3 research/pcmax_hybrid4/check.py --cnf /tmp/hybrid4_unsat/source.cnf \
  --certificate /tmp/hybrid4_unsat/certificate.json --drup /tmp/hybrid4_unsat/proof.drup
python3 research/pcmax_hybrid4/test.py
veripb --cnf /tmp/hybrid4_unsat/source.cnf /tmp/hybrid4_unsat/proof.pbp
```

All scripts require Python 3 standard library only; VeriPB is external.
