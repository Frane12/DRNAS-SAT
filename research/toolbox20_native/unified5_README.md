# UNIFIED5 — proof-carrying method memory (experimental)
Frozen C++20 UNIFIED4 is unchanged. A Python research layer extracts short multi-step RUP proof fragments, traces their original-clause dependencies, abstracts signed variables, independently checks every macro by RUP and exhaustive truth tables, and freezes a reusable catalog before evaluation. No formula names, family labels or reference answers are used for matching. Family labels are used only in experimental partitioning, provenance/ranking by diversity during training, and reporting.
30 training cases (random3, circuit, mixed); 30 disjoint fresh-seed synthetic test cases (colour, Tseitin, random3). Colour and Tseitin are held-out families for the memory learner, not necessarily unseen by the frozen solver's historical development. Paired baseline and memory, alternating order, one logical CPU, 5 s end-to-end wall cap, no CDCL fallback, same solver binary. Training cost reported separately. Matching is bounded signed-clause subgraph matching, not an unbounded assignment search. A macro can be reused only if all instantiated premises are present and each step passes RUP. Each learned prefix is independently checked against the original source. SAT models checked on original bytes. UNSAT uses standard DRAT where emitted, or independently checked structural certificates on the augmented formula with separately verified RUP prefix. A gain is a verified solution in the memory arm where baseline is unresolved; regressions and PAR2 also reported. A hit alone is not proof of useful learning. No modification of main and no promotion. This is an initial proof-schema transfer experiment, not invention of new axioms or general mathematical theorems. Native port only after evidence of benefit.
