# UNIFIED7: failure-directed native frontier learning
Experimental native C++20 recovery phase inserted after unresolved shared closure and before projection; frozen UNIFIED4 baseline unchanged. Three policy candidates rank unresolved variables by source degree, residual/proof frontier, or propagation impact. Contextual RUP closure and connected pair contexts derive guarded relations; derived facts alter the frontier, and stagnation rotates the ranking. No recursive global decision search or CDCL. Stage cap 0.85 s, 512 variables, 12000 source clauses, five rounds; every emitted accepted UNSAT checked independently against original CNF, SAT model checked against original CNF.
Recreate eight known U6 misses from its pinned commit and deterministic generator as development, plus 12 new random-3SAT calibration cases. Choose policy by verified decisions, then root progress, then PAR2. Freeze selected policy before evaluation. Test 60 new synthetic CNFs in five families; separately replay the eight known misses. Three arms (UNIFIED4, native frontier degree-first control, native frontier learned policy), rotating order, one logical CPU, same 5 s external limit. If learned policy is 0, two candidate arms are identical by design and no ranking advantage can be claimed. Python is used only as corpus/experiment/policy-training harness; runtime frontier is native. This learns a ranking policy, not new general theorems or the full U6 memory system; memory integration deferred until independent benefit. No main changes or automatic promotion.
